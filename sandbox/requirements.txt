# Packages of the sandbox's private Python runtime (T2.7), not of the
# project's own environment: `python -m sandbox setup` installs exactly these
# files, checked against their hashes, into .sandbox/runtime. The sandbox has
# no network, so code that imports anything else fails with
# ModuleNotFoundError and its run is recorded as `not-runnable`, naming the
# missing modules. Adding a package changes outcomes: raise TOOL_VERSION in
# sandbox/__init__.py in the same change. Binary wheels are for 64-bit
# Windows and CPython 3.13, the target machine.
#
# Chosen from the prompt sets (prompts/pipeline, prompts/math,
# prompts/engineering) and what code for them most often imports:
# - numpy, scipy, sympy, matplotlib (drawn with the Agg backend, to files):
#   the math and engineering tasks (drag, amortization, titration, fits,
#   beams, springs, heat sinks) and their plots.
# - pandas: CSV work in csv-to-database, data-validation, log-aggregation.
# - SQLAlchemy: the usual database layer for csv-to-database besides the
#   standard library's sqlite3.
# - requests: the usual HTTP client for daily-api-fetch (served by the stub,
#   see docs/sandbox.md).
# - Pillow: image-resize; nothing in the standard library reads JPEG or PNG.
# - PyYAML: rules and settings files (data-validation), workflow files
#   (ci-workflow).
# - pydantic, jsonschema: the common validation libraries for data-validation.
# - python-dateutil: date parsing in the CSV cleaning rules.
# - click, tqdm: command-line entry points (log-aggregation asks for one) and
#   progress bars (image-resize).
# - tzdata: time zone data for zoneinfo, which Windows does not provide.
# - pytest: runs the tests an output brings (unittest tests too).
# Left out: HTTP clients that need asyncio (httpx, aiohttp: the sandbox
# cannot make sockets, and asyncio needs them), schedulers that keep a
# program running (schedule, APScheduler), heavy statistics and learning
# libraries (statsmodels, scikit-learn), OpenCV, seaborn and plotly. Their
# absence is recorded per run, so it can be counted.
#

# dependencies are pinned too, so pip installs nothing it was not told to.
